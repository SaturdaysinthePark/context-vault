Context Vault keeps short, current facts gathered from the sources the person has connected, such as Gmail, Google Drive and Notion. Each fact is a context card: one order, delivery, trip, reservation, appointment, bill or document, with its status, its date and the source it came from.

## When to use the vault

Use it when the answer depends on something only the person would have, and a card could hold it. Typical requests:

- When a package or order will arrive, or whether it has shipped.
- When a flight leaves, a hotel stay starts, or a booking is.
- When and where an appointment or reservation is.
- When a bill is due, how much it is, or when a subscription renews.
- What a document or note of theirs says.

The person does not have to name Context Vault. If they name a source instead, such as "in my Gmail" or "from Google Drive", treat that as a request to look in the vault and limit the lookup to that source.

## How to look something up

1. Call the look up personal context tool first. Pass the distinctive words from the request as the topic: the product, merchant, person, place or document title. Leave out filler such as "when" or "my".
2. Set the source only if the person named one. Set the kind only if the request is clearly about one kind of item.
3. If nothing comes back, try once more with fewer or different key words before saying nothing was found.

## How to answer

- Answer from the card's summary. It already states the status and the date in full.
- Say the date the way the person would want to hear it, and include the time when the card has one.
- If more than one card matches, use the one whose title best matches the request. If two are equally likely, ask which one they mean.
- Mention the source briefly when it helps, for example "according to your Gmail".
- Each card has a last-updated date. If it is more than a day or two old and the answer is time-sensitive, such as a delivery, say when it was last updated.

## What to avoid

- Do not guess a date, status or amount that the card does not state.
- Do not read out reference numbers, tracking numbers or amounts unless the person asks for them.
- If the person wants the newest information, use the check for updates tool, then look the topic up again.
- To save something new for later, use the capture memory tool instead of this lookup.
